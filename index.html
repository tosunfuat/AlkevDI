Otomatik Google E-Tablo Webhook Entegrasyonu

Canlı Senkronizasyon

Öğrenciler formu her doldurduğunda yanıtlar doğrudan sizin Google E-Tablonuza yeni bir satır olarak eklensin.

Google E-Tablo Webhook Kurulumu (2 Dakikada Yapın)
  1. Yeni bir Google E-Tablo açın. İlk satıra şu başlıkları yazın: Zaman Damgası, Öğrenci Adı, Kriter, Mekanizma, Hikaye/Mekan, Yanlış Karakter, Çılgın Fikir.
  2. Üst menüden Uzantılar > Apps Script'e tıklayın.
  3. Açılan editördeki her şeyi silip aşağıdaki hazır kodu yapıştırın ve Dağıt (Deploy) > Yeni Dağıtım > Web Uygulaması seçin.
  4. Erişim yetkisini: "Herkes" (Anyone) olarak ayarlayın ve çıkan Web App URL'sini kopyalayıp yukarıdaki kutucuğa yapıştırın!
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.timestamp || new Date().toLocaleString("tr-TR"),
      data.studentName || "",
      data.criteriaLabel || data.criteria || "",
      data.mechanismIdea || "",
      data.storySetting || "",
      data.wrongItemCharacter || "",
      data.crazyIdea || ""
    ]);
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
